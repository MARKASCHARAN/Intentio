# Skill: MCP Tool Calling Implementation

## Objective
Implement MCP Server with flight booking, calendar, and weather tools.

## Tools to Implement
1. **Flight Booking**: Search and book flights via API
2. **Calendar Management**: Add/check events
3. **Weather Query**: Get current weather

## Instructions
1. Create `backend/mcp/index.js` - MCP server entry
2. Create `backend/mcp/tools/flightBooking.js`
3. Create `backend/mcp/tools/calendar.js`
4. Create `backend/mcp/tools/weather.js`
5. Register tools in MCP server
6. Connect MCP server to agent configuration
7. Test tool calling with sample requests
