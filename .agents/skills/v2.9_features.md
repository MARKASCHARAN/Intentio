# Skill: Agora v2.9 Features Implementation

## Objective
Implement all brand new Agora v2.9 features released July 2026.

## Features to Implement
1. **Managed Mode**: Use Deepgram ASR, OpenAI GPT, OpenAI TTS without API keys
2. **Manual Turn Control**: SoS/EoS over RTM for structured workflows
3. **Agent State Notifications**: Real-time listening/thinking/speaking events
4. **Pre-recorded Greeting Audio**: URL-based with TTS fallback
5. **RTM Enablement**: `enable_rtm: true` for state events

## Instructions
1. In agent config, set all ASR/LLM/TTS to `credential_mode: "managed"`
2. Enable `advanced_features.enable_rtm: true`
3. Create UI components: AgentVisualizer, StateIndicator for real-time states
4. Implement push-to-talk with manual turn control
5. Add pre-recorded greeting URL to agent config
