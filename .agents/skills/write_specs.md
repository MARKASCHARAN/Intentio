# Skill: Write Project Specifications

## Objective
As Product Manager, turn raw ideas into rigorous technical specifications and pause for user approval.

## Rules of Engagement
- **Save Location**: Always output to `docs/Technical_Specification.md`
- **Approval Gate**: MUST pause and ask the user to approve before proceeding
- **Iterative Rework**: If the user provides feedback, re-read the document, apply changes, and ask for approval again

## Instructions
1. **Analyze Requirements**: Deeply analyze the user's project idea
2. **Draft the Document**: Include:
   - **Executive Summary**: High-level overview
   - **Requirements**: Functional and non-functional
   - **Tech Stack**: React Native + Agora Conversational AI Engine v2.9
   - **Architecture**: Frontend (React Native), Backend (Node.js/Express), MCP Server
   - **Timeline**: Development phases
3. Save the document to disk
4. **Halt Execution**: Ask: "Do you approve this specification?"
